A starting estimate, with the assumptions in view. Review the glucose pattern, regimen, and individual circumstances before prescribing.

For clinician use. This tool estimates a full basal–bolus starting regimen for clinician review in insulin-naïve gestational diabetes. It does not determine whether insulin is needed. Patients should not use these results to start or change insulin.

03 / SCOPE & EVIDENCE

Know what the estimate assumes

One starting-dose model

This tool retains the original calculator’s 0.7 / 0.8 / 0.9 units/kg/day factors. The MEMS 2024 guide lists these trimester-based factors; ADA 2026 supports individualized insulin management, not this exact calculator or a universal 50/50 split.

The exact day boundaries, current-weight basis, 50/50 allocation, and rounding policy are implementation choices reviewed for this release. This simplified model has no separate late-third-trimester increase.

Outside this tool’s scope

Preexisting type 1 or type 2 diabetes; an existing insulin regimen; pump settings; correction doses; isolated fasting or isolated postmeal treatment; intrapartum or postpartum dosing; acute illness or ketosis; steroid-related changes; significant renal impairment; and recurrent hypoglycemia require an individualized approach.

Supported input range: 1w0d–42w0d and 30–200 kg. These are software limits, not physiological safety thresholds. Glucose readings, meal carbohydrate intake, and insulin sensitivity are not evaluated.

Transparent rounding

Calculate with full precision, round the total to the selected increment, then allocate that total in integer increments. Halfway totals round upward; an odd increment in the basal–bolus split goes to basal. All displayed doses sum to the rounded total.
