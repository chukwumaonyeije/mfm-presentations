# Prenatal Exome Sequencing in Structurally Normal Fetuses: Critical Appraisal

40-slide clinician journal-club presentation, prepared for OpenMFM from the supplied appraisal and verified against the open-access 2025 article.

Open `index.html` directly in a browser. The deck is standalone: all CSS, diagrams, and navigation are embedded, with no external runtime dependencies. Internet access is needed only when opening linked sources.

- Next: Right arrow, Space, PageDown, or click the right two-thirds of a slide.
- Previous: Left arrow, PageUp, or click the left third.
- Home / End: first / last slide. The slide selector jumps to a section.
- Hash links such as `#slide-11` support direct access and browser Back/Forward.
- On touch screens, swipe horizontally; content can scroll vertically.
- Presenter notes toggles the explanatory notes; `presenter-notes.md` contains the same notes.
- References opens the source list. Escape closes it.
- Print / PDF exports all slides, one slide per landscape page, without presenter notes.

The primary paper’s search ended September 25, 2024 and was repeated before submission. This is a critical appraisal of that paper, not a systematic update of evidence published afterward. The qualitative certainty ratings and APA/OpenMFM implementation recommendations are appraisal judgments, not a formal GRADE assessment or an adopted institutional policy.
