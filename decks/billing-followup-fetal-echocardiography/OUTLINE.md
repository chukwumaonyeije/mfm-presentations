# OpenMFM Presentation Standard v1.0: Slide Outline
# Topic: Billing for Follow-up Fetal Echocardiography (CPT 76826, 76828, 93325)
# Audience: Billers, Sonographers, MFM Physicians, and APPs

---

## Stage 0 — Educational Design

### 1. Single Most Important Educational Message
Accurately recognizing, performing, documenting, and billing a focused cardiovascular reassessment as a **Follow-up Fetal Echocardiogram (CPT 76826 + 76828 + 93325)**—rather than defaulting to a routine OB ultrasound (CPT 76816/76811)—is essential to reflect the high cognitive and technical medical necessity of fetal cardiac care while maintaining ironclad coding compliance.

### 2. Intended Audience & Stakeholder Adaptation
- **Sonographers:** Master the mandatory technical acquisition protocol (standard 2D sweeps + cine clips, spectral Doppler traces, color Doppler velocity mapping) and worksheet flagging.
- **MFM Physicians & APPs:** Master the distinct standalone reporting architecture, mandatory attestation components, interval change documentation, and parent-child code rules.
- **Billers & Coders:** Master CPT code combinations (76826 + 76828 + 93325), prerequisite baseline checks (76825/76827), modifier usage (Modifier 59/XE for concurrent OB scans), and ICD-10 medical necessity linkage.
- **Practice Managers & Schedulers:** Implement dedicated EHR order sets and scheduling templates that prevent downstream undercoding and claim rejections.

### 3. Common Misconceptions to Correct
1. *Misconception:* "If we perform a growth scan on the same day as a cardiac follow-up, we can only bill 76816."  
   *Reality:* Both are billable when clinically indicated, provided distinct documentation exists and Modifier 59 (or XE) is appended to 76816.
2. *Misconception:* "Any re-scan of the heart qualifies as a follow-up fetal echo (76826)."  
   *Reality:* 76826 requires a documented baseline complete fetal echo (76825) and a documented preexisting cardiac lesion or high-risk indication. Without a baseline, the exam is a complete study (76825/76827).
3. *Misconception:* "Color Doppler (93325) is bundled into the fetal echo base code."  
   *Reality:* In fetal echocardiography, CPT 93325 is a distinct add-on code reportable alongside 76826/76828 when color flow velocity mapping is performed and archived.
4. *Misconception:* "Static 2D images are sufficient to bill 76826."  
   *Reality:* ASE and SMFM standards require real-time cine loops of the beating heart across standard segmental cardiac views.
5. *Misconception:* "Spectral Doppler (76828) can be billed whenever we use color."  
   *Reality:* 76828 requires saved, measured spectral Doppler velocity waveforms (pulsed-wave / continuous-wave), not just color Doppler.

### 4. Prerequisite Knowledge
- Basic fetal cardiovascular anatomy and standard screening views (4CV, LVOT, RVOT, 3VV, 3VT).
- Fundamentals of Doppler ultrasound (color flow mapping, pulsed-wave, continuous-wave).
- Structure of CPT coding, RVUs, parent-child code relationships, and NCCI edit rules.

### 5. Key Clinical Decisions
- Is this a baseline initial study (→ 76825/76827) or a targeted follow-up (→ 76826/76828)?
- Was spectral Doppler performed and archived (→ add 76828)?
- Was color flow mapping performed and archived (→ add 93325)?
- Is a concurrent non-cardiac OB scan performed (→ 76816-59)?
- Does the report meet all standalone audit criteria to withstand payer scrutiny?

### 6. Concepts Requiring Diagrams / Schematics
- Fetal Echo CPT Code Map & Hierarchy (Complete vs. Follow-up branching flowchart).
- The 4-Pillar Departmental Pipeline (Scheduling → Sonographer Acquisition → Physician Report → Billing Engine).
- Standard Technical Acquisition Grid (2D Cine + Color Mapping + Spectral Doppler by anatomic structure).
- Lesion-specific protocol flowcharts (Effusion, VSD/ASD, Valvular Regurgitation, Cardiomyopathy, Arrhythmia/PR Interval).
- Dual Exam Billing Matrix (Same-day 76816 + 76826/76828/93325 with Modifier 59 breakdown).

### 7. Findings that Change Management & Surveillance Intervals
- Surveillance interval titration (every 2–4 weeks for progressive lesions like cardiomyopathy or left heart obstruction; every 2–8 weeks for stable structural CHD; weekly for anti-Ro/SSA PR interval monitoring between 16–26 weeks).
- Development of hydrops, chamber disproportion, outflow acceleration, or PR interval prolongation >150 ms prompting urgent fetal cardiology referral or maternal medical therapy.

### 8. Six-Month Recall
**"Prior Complete Study → Dedicated Order → 2D Cine + Color + Spectral Waveforms → Standalone Cardiac Report → Compliant Triad Billing (76826 + 76828 + 93325)."**

- **ACOG Coding Update (2025/2026):** Obstetric Ultrasound Coding and Documentation.
- **AMA CPT Professional Edition:** Codes 76825, 76826, 76827, 76828, 93325, 76816, 76811.
